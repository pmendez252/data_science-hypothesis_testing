# Data Science - Hypothesis Testing Laboratory

Repository for the Data Science laboratory exercises.

## Project Structure

- `data/`: input datasets
- `notebooks/`: Jupyter notebooks
- `outputs/`: generated figures and results
- `src/`: reusable Python code, if needed

## Python Version

Python 3.12

## Environment Setup

Create the virtual environment:

python -m venv .venv

Activate it:

.\.venv\Scripts\Activate.ps1

Install the required packages:

pip install -r requirements.txt

## Notes

The virtual environment is not stored in GitHub. Each computer should create its own `.venv` using the same Python version and `requirements.txt`.
